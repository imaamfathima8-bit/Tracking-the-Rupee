# Tracking the Rupee

Tracking the Rupee is a data-analysis and machine-learning project that explores historical Sri Lankan rupee exchange-rate data from 2007 to 2026. The project includes data cleaning, exploratory data analysis, trend visualisation, and predictive modelling.

## Objectives

- Analyse historical exchange-rate trends
- Identify major patterns and changes over time
- Apply machine-learning models to understand exchange-rate behaviour
- Present findings through clear visualisations

## Workflow

1. Collect and load exchange-rate data
2. Clean and prepare the dataset
3. Perform exploratory data analysis
4. Create visualisations
5. Train and evaluate machine-learning models
6. Interpret the results

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
